# 📌 Customer Segmentation Mini Project

## 🔹 Overview
Machine Learning project to segment customers using K-Means clustering and visualize insights using Streamlit.

---

## 🔹 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Streamlit

---

## 🔹 Project Structure
- data/raw → Original dataset (Online Retail.xlsx)
- data/processed → customer_features.csv, customer_clusters.csv
- src/
  - data_preprocessing.py
  - clustering.py
  - evaluation.py
  - recommendations.py
- app/
  - dashboard.py
