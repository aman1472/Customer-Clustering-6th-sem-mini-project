# 📌 Customer Segmentation and Analysis System Using Machine Learning

## 📖 Project Description

Customer Segmentation and Analysis System is an intelligent Machine Learning-based application developed to analyze customer purchasing behavior and group customers into meaningful segments.

The system utilizes RFM (Recency, Frequency, Monetary) analysis along with the K-Means clustering algorithm to identify customer groups based on behavioral similarity.

---

## 🚀 Technology Stack

### Programming Language
- Python

### Libraries and Frameworks
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

---

## ✨ Features

### Data Preprocessing
- Cleans raw retail transaction data
- Removes null values and duplicate records

### Customer Segmentation
- Applies K-Means clustering
- Generates customer clusters

### Dashboard
- Interactive Streamlit dashboard
- Visualizes customer analytics
